# Descarga News Buscador Visual

## Uso

Use quando o pedido envolver imagem, thumbnail, prompt visual, busca de imagens, Meta AI, banco visual, B-roll ou referencia factual.

## Saida padrao

```text
1. Links de Pesquisa no Google (Fatos Reais)
- termo de busca 1
- termo de busca 2

2. Prompt para o Meta AI (Ingles)
...

3. Prompt para o Meta AI (Portugues)
...

4. Observacoes de consistencia Descarga News
...
```

## Processo

1. Identificar o fato real e os objetos visuais verificaveis.
2. Criar termos de busca simples e diretos.
3. Separar imagem factual de imagem satirica.
4. Usar assets locais de personagem quando o visual envolver Rafael, Mona, Doutor Dinheiro ou outro fixo.
5. Criar prompt em ingles com estilo: 2D cartoon satire, thick outlines, exaggerated faces, dirty bathroom tiles, sewer water, toilets, documents, money, microphone, dramatic lighting.

## Tema sensivel

- Preferir caricatura generica quando houver risco: politician, judge, banker, government official.
- Evitar acusacao literal no texto da imagem.
- Usar simbolos: ralo entupido, pasta sigilosa, mala de dinheiro, tribunal rachado, grafico afundando.

## Checklist

- O prompt preserva a identidade visual do canal?
- A imagem explica a noticia sem depender de textao?
- O risco de plataforma foi reduzido?
- A arte tem potencial de comentario ou replay?

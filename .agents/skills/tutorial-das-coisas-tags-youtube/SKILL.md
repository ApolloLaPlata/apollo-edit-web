# Tutorial das Coisas - Tags YouTube

Use esta skill quando o usuario pedir titulo, descricao, tags, hashtags, SEO, metadados, dados de postagem ou upload.

## Entradas esperadas

- tema ou roteiro;
- formato: Short, horizontal, microvideo ou episodio completo;
- palavra-chave principal;
- se deve usar `#TutorialdasCoisas`;
- grau de protecao contra clickbait.

## Saida obrigatoria

Entregue:

- Titulo
- Descricao
- Hashtags de descricao, se fizer sentido
- Tags de backend

## Titulo

Prioridade:

1. acao buscada;
2. objeto principal;
3. beneficio/tempo;
4. pista sutil de humor quando necessario.

Exemplo de forma:

`Como DESENTUPIR a Pia RÁPIDO (Truque Caseiro) 🌀`

Quando o usuario pedir, incluir `#TutorialdasCoisas` no titulo. Caso contrario, preservar titulo mais limpo.

## Descricao

Inclua:

- primeira frase com a dor real;
- primeira ou segunda frase com aviso ironico de humor/parodia;
- resumo do absurdo;
- CTA curto;
- `#TutorialdasCoisas` quando pedido.

Nao despeje o bloco de tags de backend na descricao.

## Tags de backend

Regras:

- sem `#`;
- separadas por virgula;
- long-tail e pesquisaveis;
- perto de 450 caracteres;
- incluir erro comum/variante se fizer sentido;
- misturar tutorial real + nicho adjacente + identidade do canal.

Ordem recomendada:

1. busca exata;
2. variacoes naturais;
3. problema domestico/tecnico;
4. formato tutorial;
5. humor absurdo/parodia;
6. Tutorial das Coisas.

## Validacao

Rejeite tags:

- grudadas como hashtags;
- curtas demais;
- genericas demais;
- com `#`;
- sem relacao com a busca;
- que prometem risco, cura ou resultado impossivel como instrucao real.

## Guardrails

- Nao confundir tags de backend com hashtags publicas.
- Nao despejar muitas tags na descricao.
- Nao prometer solucao tecnica real se o video vira parodia sem pagamento minimo.
- Priorizar titulo, thumbnail e descricao como metadados principais; tags sao apoio.

# Descarga News Comunidade

## Uso

Use quando o pedido envolver comunidade, comentario, tweet, X, legenda curta, enquete, comentario fixado, resposta a fas ou post com imagem 1:1.

## Saida curta

```text
Legenda (ate 280 caracteres):
Prompt de imagem 1:1:
Pergunta para comentarios:
```

## Regras

- Relacionamento, nao texto institucional.
- Tom de zoeira com carinho acido.
- Sempre terminar com pergunta comentavel quando a plataforma permitir.
- Imagem 1:1 sem borda preta.
- Pouco texto na imagem; se houver texto, usar frase curta.
- Usar raleiros, ralo, descarga, Sanitopolis, privada, esgoto e personagem quando fizer sentido.

## Comentarios

Responder in-character quando isso aumentar comunidade. Nao brigar com inscrito comum. Criticar sistema, instituicao, narrativa ou absurdo da pauta.

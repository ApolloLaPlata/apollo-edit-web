# Dark Trap Radio Suno Beat Pack

## Quando usar

Use quando o pedido for gerar beat, prompt musical, variacoes de musica, ficha tecnica, pack de stems ou organizacao de produto musical.

## Entradas esperadas

- Mood ou tema.
- BPM desejado ou duracao.
- Intensidade: downtempo, hard, cinematico, agressivo, hipnotico.
- Uso: live 24/7, beat individual, short, venda/licenca, background.
- Origem/licenca quando a faixa ja existir.

## Saida padrao

- Nome de beat em ingles.
- Prompt Suno principal.
- 3 variacoes de prompt, se util.
- Ficha tecnica minima.
- Estrutura de pasta/stems recomendada.
- Alertas de licenca comercial.

## Prompt base

```text
dark trap instrumental, 145 BPM, heavy distorted 808, sliding bass, detuned bells, hazy purple pads, sparse half-time drums, reversed vocal textures, cinematic underground atmosphere, neon urban night, wide immersive mix, built for late-night headphones
```

## Ficha tecnica minima

- Titulo.
- Data.
- Ferramenta/modelo.
- Plano/licenca de geracao.
- Prompt original.
- BPM/mood.
- Arquivos gerados.
- Stems disponiveis.
- Status: bruto, master, tagged, clean, visualizer, publicado, produto.

## Estrutura de pasta recomendada

```text
beat-title/
  full-mix/
  tagged-preview/
  stems/
  cover/
  video/
  license/
  metadata/
```

## Checklist de qualidade

- O prompt deixa claro o universo dark trap?
- Ha direcao de BPM, timbre e atmosfera?
- A ficha registra origem e licenca?
- Os stems estao previstos como produto?
- Existe versao free/tagged e versao clean?

## Guardrails

- Verificar se a faixa foi criada em plano com uso comercial antes de vender.
- Nao assumir retroatividade comercial para musicas feitas em plano gratuito.
- Nao prometer copyright forte sobre output 100% IA; registrar contribuicoes humanas.
- Preservar stems e arquivos originais.

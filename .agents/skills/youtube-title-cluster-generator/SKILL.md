# YouTube Title Cluster Generator

## Quando usar

Use quando o pedido for criar titulos, testar titulo, fazer SEO, melhorar CTR ou criar pacote de postagem para YouTube.

## Entradas esperadas

- Tema do video.
- 20 a 50 titulos virais do nicho, quando houver pesquisa.
- Publico alvo.
- Idioma.
- Limites editoriais de honestidade/clickbait.

## Saida padrao

Para cada titulo:

- titulo em ingles ou idioma pedido;
- traducao em portugues para conferencia;
- clusters usados;
- emocao ativada;
- justificativa algoritmica;
- validacao aprovado/reprovado.

## Processo

1. Extrair palavras repetidas 3+ vezes.
2. Agrupar clusters: nicho, acao, emocao, autoridade, numerico, temporal, misterio, comparativo, instrucional.
3. Mapear emocao primaria: curiosidade, urgencia, FOMO, autoridade, indignacao, surpresa, pertencimento.
4. Criar titulos usando palavras exatas dos clusters.
5. Validar cada titulo contra os clusters.

## Checklist de qualidade

- O titulo usa termos que o publico realmente pesquisa?
- O titulo tem uma promessa clara e honesta?
- A primeira metade do titulo funciona no mobile?
- O titulo evita sinonimos fracos fora do cluster?
- A descricao/video entrega o que o titulo promete?

## Guardrails

- Nao inventar cluster quando a tarefa pede SEO serio.
- Nao usar `No Copyright` ou `Royalty Free` sem confirmacao juridica.
- Evitar clickbait que derrube retencao.
- Atualizar clusters periodicamente.
